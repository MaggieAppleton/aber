Run `npm run eval -- --compare` for live OpenAI/Claude comparison. It skips missing keys, uses isolated in-memory databases, checks counts, filing, repeats, tombstones, merges, evidence stance, tripwires and authority traces, and prints pass rates, tokens and recorded cost by job/provider. Embeddings stay on OpenAI for both providers. Reports go to the ignored `evals/results/` directory.

The default run budget is $1, bounded by `DAILY_SPEND_CAP_USD`; use `--budget 0.25` or `--limit 2` for a smaller run. The budget is checked before every model step; one in-flight provider response can take it slightly over the cap. `--fake` exercises the same SDK/tool/database loop without network calls or API keys. Fake results test plumbing and labelled fixtures, not model quality.

Use `--case cheap-model,memory,e7` to rerun named fixtures; the report's requested count reflects this selection.
