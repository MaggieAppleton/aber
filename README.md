# Aber

A personal tool for collecting signals about where technology is heading, growing them into themes and theories of the future, and turning those theories into things to prototype.

The local app lives in [app/](app/README.md). It uses React, a localhost Node server, SQLite, and typed tools shared by the interface and agents. Setup, capture examples and verification commands are in the app README.
