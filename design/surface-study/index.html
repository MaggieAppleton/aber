A surface language for Aber, built from four switches

The grammar, the spatial model and the density stay exactly as the design model fixes them. What changes is layers 3 and 4: material, colour, light and motion. Every component on this page is written once against semantic tokens. Instead of fixed bundles, pick each layer separately: material (shadow, radius, motion), a neutral scale from Radix or Tailwind, an accent, and whether objects carry their own colour. Hover, press, focus and tab through everything: it is all live.

Grey by rule

Colour is reserved for alarms

Blue is new, red is challenge, green and amber are confidence. That is correct, but it leaves colour no everyday job, so every resting surface is grey. Shadows at 0.5 px ring plus 2 px blur read as borders, which flattens the tiers.

One state model for everything you can act on

Rest, hover, press, selected, focus and disabled, forced on so they can be compared. Hover is a state layer, never a lift: cards only rise when they are selected or picked up, which keeps "lift is a promise". Focus is always a 2 px ring in the accent, separate from selection.

Colour roles

My read, and what needs your call

Recommendation · moderate confidence

Crisp, Slate, Ink accent, object colours on. The colour wheel is already crowded: blue, red, green and amber are taken by meanings. Object colours add three more hues, so a coloured accent on top of them starts to compete (the page warns when that happens). Pick one colour system: either objects carry colour and the accent stays ink, or objects stay grey and one brand accent (Teal or Orange) does the work. The first gives colour a job everywhere; the second is calmer.

Decisions for you

  • Should colour mean object type? It adds a meaning to the encoding map and means prototype status can no longer borrow blue and green.
  • Should the accent mean "you are acting here"? This also splits the focus ring away from the blue "new" dot, which share a tint today.
  • Keep "hover never lifts"? I kept it. Cards rise only when selected or dragged.
  • Which neutral? I would pick Slate or Zinc; Sage leans green next to the jade theme colour.
  • Font: Inter today. Each material shows a candidate: Geist (Crisp), IBM Plex Sans (Paper, already in design/space-and-motion/assets), Figtree (Soft).

If you pick one, the path

  • Replace the literal dump in design-tokens.css with about 60 semantic tokens, as on this page.
  • Add one shared .act state model (hover, press, focus, selected, disabled) and delete per-surface hover rules.
  • Move the five shadows and z-indices to tier tokens, then migrate surfaces one file at a time behind screenshot checks.
  • Dark mode becomes one more token block, though it is not needed for v1.
