Stage: the app's current layout, unchanged. Only colour changes here.

A Clean light

Near-white and barely warm, crisp ink, fresh light type tints and a jade primary. Closest to Foglamp.

B Warm paper

Stone and sand, earthy muted types (ochre, rust, moss, slate, heather, plum) and a deep teal primary. A notebook, not a dashboard.

C Ink on linen

Warm off-white with near-black ink and a black primary; dusty pastel tints. Teal only marks new and focus.

D Studio grey (agent's pick)

True neutral grey with a clearly sunk rail and white cards. With no tint in the neutrals, the six type glyphs and jade are the only colour, so they read vividly: calm surface, vivid where it counts.
