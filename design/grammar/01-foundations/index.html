Object glyphs

One Phosphor glyph per object, neutral in every state: the shape carries the type, so jade never competes with a type colour. Glyphs are the app's OBJECT_ICONS (Pulse, Binoculars, Target, PencilRuler, TrayArrowDown) plus Signpost for tripwires. Regular at rest, fill when selected. Suggestion has no app icon, so it takes Sparkle with a dashed edge: dashed already means "not yet mine". Click a tile to select it.
