From Maggie (PRIOR-DECISIONS.md, 1 to 4 Nov):

  • Layout and navigation stay as the app has them; jigs restyle, they don't re-layout. The pane aligns to the top of the main area.
  • Per-type object colour is back (4 Nov, reverses 1 Nov). Neutral tone is a dial; the default system is D Linen, bright types (00-colour): linen neutrals, bright type colours, black primary.
  • Jade accent means "you are acting here": focus ring, new dots, current view, primary (unless black wins above).
  • Phosphor Regular 16; fill only when selected. Glyphs from OBJECT_ICONS plus Signpost; Sparkle for suggestions.
  • Geist and Geist Mono; 11/12/13/20 at 13/1.4; 15 for modal titles; names 600.
  • 4px grid; rows 30, controls 28, card padding 12. Radii 4/7/10/14 + pill, concentric.
  • Buttons 28px (26 small), radius 7, 12/500; secondary is white with a hairline. Dismiss left of Accept; X only closes fleeting surfaces.
  • Selection is neutral, light and raised; hover a 5% state layer; press 0.98. Dashed means not yet mine.
  • Challenge red, confidence rose green, fell amber. Shadows mean height only.

Decided by the agent; change if you disagree:

  • Selected card: the decided neutral raised style (--sel) on white cards, as the app has it. The earlier white-list vs sunk-list choice is retired; it doesn't arise in this layout.
  • Hero numbers use the 20px title size. The current layout has no hero numbers, so a fifth size isn't worth adding yet.
  • Field labels use ink 2, not ink 3, so every label passes 4.5:1.
  • "Building" shows in jade text until DI-007 is decided (you wanted green).

Object glyphs

One Phosphor glyph per object, in its type colour on a pale tint of the same hue (4 Nov: type colour is back). No type hue sits near the accent, which means "you are acting here". Glyphs are the app's OBJECT_ICONS (Pulse, Binoculars, Target, PencilRuler, TrayArrowDown) plus Signpost for tripwires. Regular at rest, fill when selected. Suggestion has no app icon, so it takes Sparkle with a dashed edge: dashed already means "not yet mine". Click a tile to select it.
